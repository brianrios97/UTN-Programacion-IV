# UTN - Programación IV 🎓

Repositorio correspondiente a la cátedra de **Programación IV** de la **Tecnicatura Universitaria en Programación** (Universidad Tecnológica Nacional - UTN).

---

## 📂 Contenido del Repositorio

* **[Unidad 1: Fundamentos de Spring Boot y JPA](./Unidad_1_Fundamentos/README.md):**  
  Implementación del modelo de dominio, mapeo objeto-relacional (ORM), persistencia con Spring Data JPA y base de datos en memoria H2.

* **[Unidad 2: Desarrollo de API REST y Swagger](./Unidad_2_API_REST/README.md):**  
  Construcción de API REST profesional completa con arquitectura en capas (*Controller, Service, Repository, DTOs*), manejo global de excepciones y documentación interactiva con **Swagger / OpenAPI 3.0**.

---

## 🛠️ Tecnologías Principales
* Java 21 / 24
* Spring Boot 3.2.5
* Spring Data JPA / Hibernate
* SpringDoc OpenAPI UI (Swagger 3)
* H2 In-Memory Database
* Lombok
* Maven (Estructura Multi-Módulo)
